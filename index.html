A short path to inference

From a local model to a first reply.

Get a matching build from the releases or build from source. Keep its runtime libraries alongside the executable, then download a compatible chat model. Replace the example path with its complete GenAI model directory.

01 — Start the serverShell / macOS
./onnx-genai -s \
  -m /path/to/chat-model \
  -h 127.0.0.1 \
  -p 8080

On Windows, use onnx-genai.exe with the same flags and your local model path. Leave the server running. In another terminal, wait until model discovery succeeds; starting the process does not mean model loading is complete.

02 — Discover loaded modelsShell
curl http://127.0.0.1:8080/v1/models

Then send a message to the loaded chat model:

03 — Make a requestShell / macOS
curl http://127.0.0.1:8080/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{
    "messages": [
      {"role": "user", "content": "What can I build with local AI?"}
    ],
    "max_tokens": 128,
    "temperature": 0.7,
    "stream": false
  }'
Keep local inference local.

The examples bind to 127.0.0.1. Do not expose the listener to a network without deliberately securing access. Model downloads require a connection; review each model's license before deployment.
